Lu-177治療患者スケジューラ

プルヴィクト（Lu-PSMA-617）・ルタテラの入院治療スケジュールを、発注締切・祝日・病床の重複まで自動で考慮して管理するデスクトップアプリの操作手引きです。

1このアプリでできること

患者を登録すると、治療間隔・営業日・祝日・薬剤の発注締切・病床の重複を自動で考慮して、全サイクルの入院日・治療日・退院日を計算します。予約が重複しないように、また過去日や発注に間に合わない日には予約できないようになっています。

患者管理

患者ごとに全サイクルの日程を自動計算・一覧表示。

治療日の調整

ボタンや手動編集で日程変更。重複や締切超過は自動で防止。

カレンダー・帳票

病室占有カレンダー、月次帳票、患者用予定表を印刷。

暗号化・共有

データはパスワードで暗号化。共有フォルダで全員が同じ予定を閲覧。

はじめに覚える3つ
  • 解除パスワード＝毎回アプリを開くときに全員が使う共通パスワード。
  • 管理者パスワード＝解除パスワードを変更するときだけ必要（管理者のみ）。
  • 保存先＝患者データの置き場所。院内共有フォルダにすると全員で共有できます。

2アプリを起動する

  1. デスクトップまたはスタートメニューの 「Lu-177治療患者スケジューラ」 をダブルクリックします。
  2. 初めて開いたときはパスワード設定画面、2回目以降はロック解除画面が表示されます。
画面はこれだけ

このアプリは患者管理の一画面に絞っています。上部のボタンは 保存先 パスワード変更 ロック の3つです。

3初回セットアップ（管理者が行います）

導入したPCで最初に一度だけ行う設定です。管理者が実施してください。

① 解除パスワードを設定

  1. 初回起動で「初回セットアップ」画面が出たら、8文字以上のパスワードを2回入力して設定します。
  2. これが以後、全員がアプリを開くときに使う共通の解除パスワードになります。
重要：パスワードを忘れると復元できません

データは解除パスワードで暗号化されています。忘れると患者データを開けなくなります。安全な場所に必ず記録してください。

② 保存先（共有フォルダ）を設定

全員で同じ予定を共有する場合、患者データの保存先を院内共有フォルダに変更します。

  1. 上部の 保存先 をクリック。
  2. 「共有フォルダを選択する」→ 院内共有フォルダを指定。
  3. 自動で再起動します。以降、そのフォルダのデータを読み書きします。

2台目以降のPCも、同じ手順で同じ共有フォルダを指定してください。全員が同じ患者スケジュールを見られます。

③ 管理者パスワードを設定

解除パスワードは全員が知っているため、そのままでは誰でも変更できてしまいます。変更を管理者だけに限定するため、別の管理者パスワードを設定します。

  1. 上部の パスワード変更 をクリック。
  2. 初回は「管理者パスワードの設定」画面になります。6文字以上で設定します。
  3. 以降、解除パスワードの変更にはこの管理者パスワードが必要になります。

導入直後にすぐ設定してください。 設定するまでは誰でも最初の管理者パスワードを決められてしまいます。

4ロックを解除する（毎回）

  1. アプリを開くと「Lu-177治療患者スケジューラ」のロック画面が出ます。
  2. 解除パスワード（共通）を入力して「解錠」をクリック。
  3. 患者管理画面が表示されます。

作業を終えたら、上部の ロック を押すと再びパスワードが必要になります。離席時はロックを推奨します。

5患者を登録する

  1. 「患者を追加」欄に 患者名 を入力。
  2. 治療タイプ を選択：プルヴィクト（Lu-PSMA-617）または ルタテラ。
  3. 開始希望日 を選択（今日より前は選べません）。
  4. 予定サイクル数 を入力（プルヴィクト最大6回／ルタテラ最大4回）。
  5. ＋ 患者追加 をクリック。全サイクルの日程が自動作成されます。
自動計算される内容
治療間隔プルヴィクト＝6週間（42日）／ルタテラ＝8週間（56日）
入院日治療日の前営業日
退院日治療日の翌日

空いていれば理想の間隔どおりに、混雑していれば重複しない範囲で自動的に後ろ倒しして全サイクルを登録します。希望日と違う日になった場合は理由をポップアップで表示します（例：発注締切、祝日週、他患者と重複 など）。

6スケジュールの見方

「登録患者一覧」で各患者の サイクル（n） を押すと、サイクル表が開きます。

列意味
治療日お薬を投与する日。
前回間隔前のサイクルからの日数。標準（42/56日）どおりなら黒字、ずれると 橙字（+日数） で表示。
入院日 / 退院日治療日から自動計算。
ステータス予定 / 完了 / キャンセル。
メモ自由記入。

他の患者と入院期間が重なるサイクルは赤く強調され、患者名の横に「日程重複あり」バッジが出ます（通常は自動で重複を防ぐため、手作業で無理に重ねた場合などに表示されます）。

7治療日を調整する

ボタンで前倒し・延期

各サイクルの行にあるボタンで日程を動かせます。押したサイクル以降が連動して調整されます。

−14日 −7日（前倒し） +7日 +14日 +21日（延期）

  • 空いている治療日へ自動で配置します（他の予約とは重複しません）。
  • 変更できないときは理由をポップアップで表示（例：発注締切超過、2週間以内に空きがない など）。
  • 押した直後にメッセージ欄へ 元に戻す ボタンが出ます。押すと延期前の状態に戻ります。

手動で細かく変更（編集）

  1. サイクル行の 鉛筆アイコン をクリック。
  2. 治療日を入力すると、入院日・退院日は自動で更新されます。
  3. 必要ならステータス・メモも変更し、チェック（✓）で保存。

選んだ日が使えないときは中央にポップアップが出て保存されません（祝日・日曜・非入荷日・治療対象外週、他患者と重複、発注締切超過、16週超過 など）。別の日を選び直してください。

治療日を変えたとき、後続サイクルも間隔どおりに直したい場合は「後続サイクルを治療間隔から自動再計算する」にチェックを入れて保存します。

8自動でかかるルール

予約ミスを防ぐため、次のルールが常に働きます。

ルール内容
重複させない他の患者と入院期間が重なる日は登録できません。
先着優先先に入れた予約は動きません。後から入れる方が空き日へ調整されます。
発注締切治療日の週の2週間前の月曜17時が薬剤の発注締切。締切を過ぎた治療日は予約できません（=最短でも約2〜3週間先から）。
週1件1週間にLu-177治療は最大1件まで。
祝日の週は除外月・火・水のいずれかが祝日の週は薬剤が届かないため、治療日にできません（稼働率の計算からも除外）。
非入荷期間お盆・年末年始などは治療日にできません。
延期は最長16週副作用等での延期は前回から最長16週（112日）まで。
過去日にしない今日より前の日付には予約できません。

9印刷する

印刷は各ボタンから行います。Windowsの印刷ダイアログが開き、プリンターのほか「PDFとして保存」も選べます。

患者用予定表

患者さんにお渡しする、やさしい表現の予定表。全サイクルの入院・投与・退院日を大きく表示し、持ち物・注意事項つき。

印刷

スタッフ用の詳細スケジュール。

月次帳票

表示中の月の入院予定を一覧で印刷。

「病室占有スケジュール」内の 月次帳票 / 印刷 ボタンから、月単位の帳票やカレンダーも印刷できます。

10カレンダーと病室稼働状況

病室占有スケジュール

カレンダー表示とタイムライン表示を切り替えられます。カレンダーでは入院・治療・退院を色分けし、祝日には「祝」、治療対象外週（月・火・水が祝日）には斜線と「対象外」を表示します。「前月／翌月」で移動できます。

病室稼働状況

上部のカードに、カレンダーで表示中の月の稼働状況を表示します。

  • 治療日（火）：その月の治療可能な火曜日の数（薬剤の届かない祝日週などは除外）。
  • 予約済み：その月に予約された治療件数。
  • 空き：残り枠。稼働率＝予約済み ÷ 治療日。

当面は火曜日のみの運用を前提に集計しています。運用が変わった場合は管理者にご相談ください。

11パスワードを変更する（管理者のみ）

解除パスワード（共通）の変更

  1. 上部の パスワード変更 をクリック。
  2. 管理者パスワードを入力。
  3. 新しい解除パスワード（8文字以上）を2回入力して「変更する」。

管理者パスワードが正しくなければ変更できません。これにより、一般スタッフは解除できても共通パスワードを勝手に変えられません。

管理者パスワード自体の変更

同じ画面の下部「管理者パスワードを変更する」から、現在の管理者パスワードを入力して変更できます。

新しいパスワードは必ず記録してください。忘れると管理者操作（解除パスワードの変更）ができなくなります。

12データ共有と注意点

院内共有フォルダを保存先にすると、複数PCで同じ患者スケジュールを共有できます。安全に使うため、次を守ってください。

同時編集はしない

複数の人が同時刻に登録・変更すると、データが壊れる恐れがあります。編集は1人ずつ行ってください（閲覧は同時でも問題ありません）。

  • 解除パスワードは全員共通です（同じ暗号化データを開くため）。
  • 共有フォルダは定期的にバックアップしてください。
  • 患者データを共有フォルダに保存するため、院内のセキュリティ規定を必ず確認してください。
  • 離席時は ロック を。

13困ったとき（Q&A）

患者を追加したのに1サイクルしか登録されない
最新版で修正済みです。アプリが古い場合は管理者に更新を依頼してください。祝日の多い時期は空き探索の結果、日程が後ろにずれることがありますが、全サイクル登録されます。
ボタンを押しても日付が変わらない／ポップアップが出る
重複・発注締切・祝日週・16週超過などで、その日には変更できない場合です。ポップアップの理由をご確認のうえ、別の日程で調整してください。
希望した開始日と違う日になった
発注締切（2週間前の月曜17時）を過ぎている、祝日の週、他患者と重複、などの理由で自動調整されています。ポップアップに理由が表示されます。
別のPCで入れたはずのデータが表示されない
両方のPCで 保存先 が同じ共有フォルダに設定されているか確認してください。異なると別々のデータになります。
パスワード変更を押しても変えられない
解除パスワードの変更には管理者パスワードが必要です。管理者にご相談ください。
解除パスワードを忘れた
暗号化のため、パスワードなしでデータを復元することはできません。バックアップの有無を含め、管理者にご確認ください。
既に重複・過去日で登録された古いデータがある
自動修正はされません。延期ボタンや編集で調整するか、削除して登録し直してください（新規登録すれば正しく配置されます）。
