Lu-177 治療スケジュール（Access版）構築手順書

VBA（マクロ）不要・クエリだけで自動計算／作成日：〔　年　月　日〕
この手順の特長
VBA（マクロ）を一切使いません。テーブルとクエリだけで、治療日・入院日・退院日・発注締切を自動計算し、同じ週の重複も自動検出します。マクロが制限された環境でも動きやすい構成です。

0用意するもの・完成イメージ

  • Microsoft Access（院内PCに導入済みを確認済み）
  • 取り込み用CSV 3ファイル（本手順書と同じフォルダ）：M_薬剤.csv / M_サイクル番号.csv / T_患者.csv

完成すると：「患者フォーム」で患者・薬剤・第1治療日・サイクル数を入れるだけで、全サイクルの日程が自動で一覧表示・印刷でき、同じ週に2件重なると赤く警告されます。

1空のデータベースを作る

  1. Accessを起動 → 「空のデータベース」を選択。
  2. ファイル名を Lu-177治療スケジュール にして、保存先を選び「作成」。
  3. 自動で作られる空テーブル「テーブル1」は、左の一覧で右クリック→閉じて、保存せず破棄してかまいません。

23つのCSVをテーブルとして取り込む

下記を3ファイルとも同じ手順で行います。

  1. 上部メニュー 「外部データ」→「新しいデータソース」→「ファイルから」→「テキストファイル」。
  2. 「参照」で M_薬剤.csv を選択 → 「現在のデータベースの新しいテーブルにソースデータをインポートする」を選び「OK」。
  3. ウィザードで 「区切り記号付き」→「次へ」、区切り記号は 「カンマ」、「先頭行をフィールド名として使う」にチェック。
  4. 文字コードで文字化けする場合は、ウィザードの「詳細設定」→コードページを 「Unicode (UTF-8)」に。
  5. 「フィールドのオプション」でデータ型を下表のとおり設定 → 主キーは「主キーを設定しない」でも可 → テーブル名を確認して「完了」。
CSVテーブル名フィールドと型
M_薬剤.csvM_薬剤薬剤=短いテキスト／治療間隔=数値(長整数)／しきい値=数値(長整数)
M_サイクル番号.csvM_サイクル番号番号=数値(長整数)
T_患者.csvT_患者患者ID=短いテキスト／患者名=短いテキスト／薬剤=短いテキスト／第1治療日=日付/時刻／サイクル数=数値(長整数)
重要：第1治療日は必ず「日付/時刻」型に、数値の列は「数値」型にしてください（文字列のままだと計算がずれます）。取り込み後に型がおかしいときは、テーブルを「デザインビュー」で開いて直せます。

3クエリを4つ作る（SQLを貼り付けるだけ）

各クエリは同じ手順です：「作成」→「クエリデザイン」→（テーブル選択画面はいったん閉じる）→ 左上「SQL表示」に切り替え → 下のSQLを全文貼り付け → 保存（クエリ名を付ける）。

① クエリ名：Q1_治療日

各患者×サイクル数だけ行を作り、治療日を計算SELECT T_患者.患者ID, T_患者.患者名, T_患者.薬剤,
       M_サイクル番号.番号 AS サイクル,
       DateAdd("d",[M_薬剤].[治療間隔]*([番号]-1),[第1治療日]) AS 治療日
FROM (T_患者 INNER JOIN M_薬剤 ON T_患者.薬剤 = M_薬剤.薬剤), M_サイクル番号
WHERE M_サイクル番号.番号 <= T_患者.サイクル数;

② クエリ名：Q2_治療予定

入院日・退院日・治療週・発注締切を計算SELECT Q1_治療日.患者ID, Q1_治療日.患者名, Q1_治療日.薬剤,
       Q1_治療日.サイクル, Q1_治療日.治療日,
       DateAdd("d",-1,[治療日]) AS 入院日,
       DateAdd("d",1,[治療日]) AS 退院日,
       [治療日]-(Weekday([治療日],2)-1) AS 治療週,
       CDate(DateAdd("d",-14,[治療日]-(Weekday([治療日],2)-1))+TimeSerial(17,0,0)) AS 発注締切
FROM Q1_治療日;

③ クエリ名：Q3_重複週

同じ週に2件以上ある治療週を抽出SELECT Q2_治療予定.治療週, Count(*) AS 件数
FROM Q2_治療予定
GROUP BY Q2_治療予定.治療週
HAVING Count(*)>1;

④ クエリ名：Q4_治療予定_チェック

一覧に「件数」を付ける（件数に数字が入る行＝重複）SELECT Q2_治療予定.*, Q3_重複週.件数
FROM Q2_治療予定 LEFT JOIN Q3_重複週
     ON Q2_治療予定.治療週 = Q3_重複週.治療週
ORDER BY Q2_治療予定.治療日;
動作確認：Q4_治療予定_チェック をダブルクリックして開くと、取り込んだ例（山田さん・佐藤さん）の全サイクルが日付付きで並べば成功です。

4入力フォームを作る（患者の登録用）

  1. 左の一覧で T_患者 を1回クリックして選択。
  2. 上部 「作成」→「フォームウィザード」。テーブルは T_患者、フィールドはすべて「>>」で選択→「次へ」。
  3. レイアウトは「単票形式」→「次へ」→ フォーム名を F_患者入力 にして「完了」。
  4. このフォームで患者を1件ずつ追加していきます（薬剤は「プルヴィクト」または「ルタテラ」と入力）。
薬剤を選択式にしたい場合（任意）：F_患者入力をデザインビューで開き、薬剤欄を右クリック→「コントロールの種類の変更」→「コンボボックス」。値集合ソースに M_薬剤 を指定すると、ドロップダウンで選べます。

5予定表を表示・印刷し、重複を色で見る

  1. 左の一覧で Q4_治療予定_チェック を選択 → 「作成」→「レポートウィザード」。
  2. フィールドをすべて選択→「次へ」を進め、レポート名 R_治療予定表 で「完了」。
  3. 重複を赤くする：レポートをデザインビューで開き、明細行の 件数 欄を選択 → 上部「書式」→「条件付き書式」→「新しいルール」。
    「フィールドの値が」→「次の値以上」→ 1 を入力 → 書式で背景色を赤に設定 → OK。
    （件数に数字が入る＝同じ週に2件以上＝重複、の行が赤くなります）
  4. 印刷は、このレポートを開いて Ctrl+P。PDF保存も可能です。

6毎日の使い方

  1. F_患者入力 で患者を登録（薬剤・第1治療日・サイクル数）。
  2. R_治療予定表（またはクエリ Q4_治療予定_チェック）で全サイクルの日程を確認・印刷。
  3. 赤い行（＝同じ週に重複）が出たら、患者の第1治療日をずらして重複を解消。

7注意点（暫定運用のための割り切り）

  • 入院日は「治療日の前日」で計算しています（治療日は火曜のため入院＝月曜）。祝日で前倒しが必要な場合は手動でご調整ください。
  • 重複回避・祝日週の自動除外は行いません。赤い警告を見て手作業で日程を調整する運用です（自動化はかえって故障のもとになるため）。
  • この Access版は正式アプリ導入までの暫定運用です。個人認証などの本格対応は、別途アプリ改修（要件定義）で進めます。
  • 患者名を扱うため、ファイルの保存先・共有は院内のセキュリティ規定・医療情報部の指示に従ってください。
